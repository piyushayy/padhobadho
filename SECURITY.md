## Reporting a Vulnerability

We take the security and integrity of student data very seriously.

If you discover a security vulnerability in PadhoBadho:

1. **Do not disclose it publicly** through GitHub Issues or public social media.
2. Email the maintainer directly at: `security@padhobadho.com` (or create a private GitHub Security Advisory).
3. Include detailed steps to reproduce the issue, potential impact, and suggested remediations if known.

We will acknowledge receipt within 48 hours and work with you on a responsible disclosure timeline.
